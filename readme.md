
# Python QR Code Generator

A simple QR Code Generator built with Python and Tkinter. It converts text, URLs, and other information into QR code images that can be previewed and saved as PNG files.

## Features

- Generate QR codes from text and URLs
- Preview QR codes in a graphical interface
- Save generated QR codes as PNG images
- Input validation and error handling
- Simple and beginner-friendly GUI

## Technologies Used

- Python
- Tkinter
- qrcode
- Pillow

## Requirements

- Python 3.9 or later
- pip

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/Python-QR-Code-Generator.git
   ```

2. Open the project folder:

   ```bash
   cd Python-QR-Code-Generator
   ```

3. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the application:

```bash
python app.py
```

Enter text or a URL, click Generate QR Code, and save the generated image as a PNG file.
